# AWA - Weather App

Small weather app that shows favorites locations, can add/remove them and the weather details for a given location.

---

This is the toy application project made for **droidcon Berlin 2026** for the talk:

> **Shift Left: Unit test your compose UI with reusable robots and BDD-style DSL**

📄 **Presentation Slides:** [droidCon Berlin 2026 Shift Left.pdf](docs/shift-left-slidev/droidCon%20Berlin%202026%20Shift%20Left.pdf)

### Talk Abstract

When testing the UI cannot be done via the normal instrumentation tests, what's left are unit tests.

Join this session to see how far unit tests can take you when verifying compose UI (permissions flow anyone?), how you can do so with reusable robot screens and how a behavior driven kotlin DSL can make all your tests understandable by everyone.

Take a shortcut and see the gotchas of junit assertions vs instrumentation ones, see the limitations of unit testing your UI and check if you could benefit from testing your UI without an emulator.
